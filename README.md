# Margin Notes

A field-notebook-style cybersecurity blog by Gwendolyn Chu.

## Run locally

1. Install Node.js 22 or newer.
2. Install pnpm, then run `pnpm install`.
3. Run `pnpm dev`.
4. Open `http://localhost:3000`.

## Production build

Run `pnpm build`, followed by `pnpm start`.

The project is a standard Next.js application and can be deployed on any host that supports Next.js.
